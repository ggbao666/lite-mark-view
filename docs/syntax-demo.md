# LiteMark View 语法演示

这是一份用来展示 **LiteMark View** 支持的全部 Markdown 语法的示例文档。 把它拖进编辑器，或者用「打开」按钮打开，就能看到下面这些内容在所见即所得模式下的渲染效果。

## 文本样式

普通文字，以及 **加粗**、*斜体*、~~删除线~~、`行内代码`。

它们可以互相嵌套：**加粗里放一段 `代码` 也没问题**，***粗斜体*** 同样支持。

## 列表

无序列表：

- 第一项
- 第二项
  - 嵌套的子项
  - 另一个子项
- 第三项

有序列表：

1. 准备环境
2. 编写代码
3. 运行测试

任务列表：

- [ ] 待办事项

- [x] 已完成事项

## 引用

> 引用区块会整体缩进，并显示一条左侧竖线。
>
> 里面同样可以放 **加粗** 和 `行内代码`。

## 表格

| 功能 | 快捷键 | 说明 |
| --- | --- | --- |
| 保存 | Ctrl+S | 写入当前文件 |
| 查找 | Ctrl+F | 打开查找面板 |
| 替换 | Ctrl+H | 打开替换面板 |
| 切换模式 | Ctrl+/ | 源码 / 所见即所得 |

## 代码块

```js

const greeting = (name) => `Hello, ${name}!`
console.log(greeting('LiteMark View'))
```

```go
package main
```

```python
def fib(n: int) -> int:
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
```

## 长段落

Markdown 的段落会按窗口宽度自动换行，一行写很长也不会出现横向滚动条； 在源码模式下打开这份文件，看到的就是磁盘上最原始的文本内容。
